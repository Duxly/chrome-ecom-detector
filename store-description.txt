💡 HOW IT WORKS

The extension analyzes each website you visit using multiple detection methods:

• DOM structure and HTML classes
• Meta tags and generator information
• CDN and script sources
• Cookie names
• JavaScript global variables

When a platform is detected, the extension badge lights up with a two-letter abbreviation (e.g., "SF" for Shopify, "WC" for WooCommerce). Click the icon to see full details including the platform name and version.
